# RedGuard AI

**Precision Visual Inspection & Component Verification Platform**

RedGuard AI is a computer vision and ML engineering project focused on detecting physical component changes, replacement, tampering, movement, damage, and visual anomalies.

## Current Release

`v0.1.0` — Component-Level Verification

## Initial Scope

The first development track focuses on electronic components and PCB inspection.

Planned capabilities include:

- image preprocessing
- precise image registration
- visual change detection
- component-level verification
- automatic component detection
- visual fingerprinting
- Siamese / metric-learning verification
- anomaly localization
- tamper and defect detection
- human review
- MLOps and production inference
